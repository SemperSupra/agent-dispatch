# R36 — pinned real extractor CLIs under disposable OS network isolation

**Scope: strictly startup compatibility, not Instagram acquisition.** Two pinned public wheel distributions (`gallery-dl==1.32.19`, `parth-dl==1.2.1`) are independently hash checked, dependency closure recorded, installed into temporary Python virtualenvs on native public Ubuntu AMD64/ARM64 GitHub-hosted runners. The only network-enabled phase is public PyPI package retrieval and installation. Each package's **real** CLI `--version` command is then invoked five times as uid/gid 65534 with zero effective capabilities in a Linux `unshare --net` namespace with no default routes.

The probe first confirms a documentation-only TCP attempt to `192.0.2.1` is rejected by the kernel. It launches each vendor's real CLI with sanitized environment (no inherited HOME, local cache, user site packages, proxy/cookies or private credentials) with a 16 KiB monitored output cap, 4-second wall deadline, `RLIMIT_AS` 512 MiB, `RLIMIT_CPU` 2/3 seconds, `RLIMIT_FSIZE` 64 KiB and `RLIMIT_NOFILE` 32. The five observations are version string, exit status, elapsed time and captured byte count. Child runs in a separate process group so failure does not leave descendants.

**What PASS means:** the pinned *actual package CLI* can start and report its version repeatedly within this specific ephemeral public-runner netns and resource configuration. It does **not** prove native extractor download logic works without network, live Instagram anonymous source support, exact media selection, per-child identity, original image bytes, throughput, production host portability or permissions/rights. A green Actions run remains G1 source **HOLD**.

This is an independent workcell from R34 baseline `b701053dcf311610fe9129dfe358d8ba8f76a50c`, separate from the local actor branch, public R35 fake extractor PR #585 and the private Winnow repository. No real Instagram URL, private source, credentials, user media, live extraction, host mutation, Agent Dispatch orchestrator, merge or release.
