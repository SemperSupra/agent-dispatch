# Frozen public multilingual reference benchmark

42 fictional case families (6 development, 36 held-out, 12 English/German/Thai each in held-out). Twelve scenario categories: direct, revision, late acquisition, future validity, conflict, reacquisition, tenant scope, unknown, identity collision, negation, untrusted text, scope decoy. Each case has a separate synthetic tenant and document family, and distinct source/lineage partitions. Multiple same-byte acquisitions within one case retain their identities. Cross-split duplicate raw bytes are rejected by the existing pipeline. Typed annotations and the explicit manually specified answer/citation oracle are separate files; only question and visible raw sources leave the context projection. The author of these public fixtures is not an independent external annotator, and public gold is not a blind secret benchmark. These cases are a useful bounded next research corpus, not evidence of human-level multilingual competence.

Run in the existing module: `go test -count=2 ./...`, `go run ./cmd/mail-benchmark contexts`, or `go run ./cmd/mail-benchmark reference`. The last command compares the existing typed resolver to a deliberately negative abstain-only control. Three seeded permutations exercise deterministic ingestion-order invariance, not model seeds. No LLM inference, optimizer training, model promotion or native PST qualification is claimed. Further genuine model comparisons need a separately bound native receipt and a new disjoint evaluation corpus. Treat raw mail as data, not instructions. The per-case fixture scope is not production authentication or a retrieval ranking benchmark.
