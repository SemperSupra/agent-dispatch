# Catalog-bound projection entry point

PrepareCatalogReviewedProjection composes the root/head-pinned lifecycle
journal, the signed review contract, derived exact inventory, existing
four-valued temporal assessor and reviewed-span-only model projection.
The trusted application constructs the catalog via Replay using root and
current head from independent custody. Visible IDs are derived from the
session, not provided by the annotation producer. Each payload must match the
catalog-admitted reviewer, producer, exact digest, registration clock and
ordered revision source endpoints. Only the exact as-of set may be submitted.
Actual reviewer signatures are still verified; root registration alone is not
a substitute. A previously admitted review can survive prospective key
revocation. Unknown/conflict do not invoke a model.

This integrates the bounded reference contracts, not an operational review
service or real independent annotation process. Catalog completeness depends
on root custody and independent semantic review. Root/key/clock provisioning,
durability, versioned review replacement, semantic adjudication, compromise
quarantine, private corpus qualification and language realization are separate
gates. Public synthetic fixtures only, no actual model inference or promotion.
