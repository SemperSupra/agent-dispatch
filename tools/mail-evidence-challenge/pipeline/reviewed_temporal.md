# Signed source annotation qualification boundary

The prior temporal adapter binds visible source bytes and acquisition time but accepts caller-supplied interpretation. This optional Go reference boundary requires externally configured tenant/policy-scoped Ed25519 public keys and exact signed source and revision annotations. Each visible source occurrence requires explicit coverage (even an empty reviewed claim list); partial or not-yet-reviewed source coverage fails closed. Claim spans are exact UTF-8 byte ranges. Signed source payload binds original digest, occurrence, acquisition/authorship, lineage, claim interpretations and recorded review time. Revision payload binds both exact source review digests, the existing reviewed correction and successor byte span. A future review cannot enter earlier knowledge; a revision cannot precede either claim review. The existing temporal resolver retains independent contradiction and half-open validity semantics. No rules can be injected through this interface.

Review credentials must be supplied by a trusted application, not the untrusted input or model. Test keys are public synthetic controls only. Signatures prove integrity and key possession, not human review, actual authority, correct interpretation, trusted clock issuance or semantic independence of the producer/reviewer. Caller identity, trust provisioning, revocation history, append-only custody, cross-language canonicalization, correction history for source review versions, and completeness of submitted revision history remain separate release gates. Authored-after-acquired data fail closed (clock skew requires separate adjudication). No native email/PST, credential management, actual reviewer enrollment, production authorization or model inference is claimed. Use the existing Go module CPU qualification.
